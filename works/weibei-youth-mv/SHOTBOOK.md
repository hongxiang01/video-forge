# 《违背的青春》MV 第 6 版 · 分镜本（黑板粉笔画，0:00–2:27）

依据：歌词解读 `lyrics_analysis.md`（用户确认主旨：被违背了的、傲慢的青春，感怀和回忆过去）；画风卡 `~/video-forge/my-styles/chalkboard-chalk/STYLE.md`；镜头方法 video-talkcraft 上游 `references/cinematography.md`、`shot-design.md`（三面分层、每个边界都要有转场处置、英雄时刻 4–6 层）。

## 0. 全局设定

- **一块巨大的黑板就是整个世界**（长镜头世界画布 long-take-world）：同一幕内所有内容画在同一块黑板的不同位置，镜头在上面推、拉、摇、移；幕与幕之间用转场。
- **颜色就是时间**：白、灰粉笔 = 现在的大人、规矩、单调；彩色粉笔（橙、天蓝、红、黄）= 青春、愿望、回忆。
- **母题升级**：白方格（规矩）→ 角落里擦不干净的彩色跳房子（残影）→ 大人用彩色粉笔头在格子上开一扇门 → 副歌整板彩色跳房子 → 少年留在彩格里，大人走回白格 → 最后格子里只剩一枚硬币和一截粉笔头。
- **歌词里的实物都要画出来**：格子、愿望（吉他和星星的小纸条）、单色和彩色的自行车、硬币、门、纸船、课桌、那段空出来的距离。
- **切点**：全部落在小节线或拍点上（song.json），镜头内的动作重拍对准拍点。
- **歌词版**：歌词用彩粉笔或白粉笔「写」在黑板空白处（逐字写出、唱完被擦），颜色跟着这句是谁在说；无字版不写。

景别缩写：大远 / 远 / 全 / 中 / 近 / 特 / 大特。运镜：推、拉、摇（上摇、下摇、横摇）、移（横移、跟移）、升、绕、定。
