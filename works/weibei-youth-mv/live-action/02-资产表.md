# 《纸船靠岸》资产表（人物、场景、道具、风格）

**用法**
1. 先用每个人物的"定妆照提示词"出参考图，每个人挑一张最满意的，在 Muse 里建成角色资产。吉他、硬币、自行车这几样反复出现的道具，最好也出一张参考图建成资产。
2. 每个镜头的提示词（`03-分镜脚本.md`）里已经写好了人物的"短描述"。生成时把"资产"列里的那几个资产一起带上。
3. Muse 如果有"负面提示词"一栏，每个镜头都填第三节那一条。
4. 两个许舟必须一眼看得出是同一个人，靠这 3 个认人点，每一镜都不能丢：**黑色粗框方形眼镜、左眼正下方一颗小黑痣、瘦长脸 + 单眼皮**。
