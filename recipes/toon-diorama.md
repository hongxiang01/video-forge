# 方案：三渲二微缩场景

> 一个放在方形木底座上的日式小场景，可以在网页里拖拽旋转缩放，三渲二描边，夜景光池 + 湿地面倒影。

## 1. 适用

- 适合做：街角、店铺、车站、小巷、屋顶、庭院等「一个地方」；收藏品、展示页、视频转台镜头。
- 不适合做：有剧情、人物表演的内容（换画风视频或 MV 产线）。
- 产线：微缩（skill 的 `references/pipeline-diorama.md`）
- 输出：单个 HTML（three.js r128，CDN 引入），可发布成 Artifact；需要视频时加转台录制。

## 2. 画风

- 来源画风：`my-styles/toon-rainy-night`。白天、黄昏、雪夜版本只改第 3 节色彩，其余数值不动。
- 关键数值：见画风卡第 2、3 节。
- 禁区：整体过亮（光要成池）、镜像文字、满屏霓虹、底座外有东西、UI 元素。

## 3. 追问补充

| 项 | 为什么要问 | 默认值 |
|---|---|---|
| 地点和主体 | 决定中心建筑 | — 必须问 |
| 时间和天气 | 决定整套光 | 雨夜 |
| 必须出现的元素清单 | 用户往往有一长串，要逐条落实 | 按地点给一版清单让用户勾 |
| 街道结构 | 转角、丁字路口、直街 | 十字转角 |
| 人物/动物/车辆 | 数量与姿态，人物不演戏 | 1–2 个静止行人 + 1 只猫 + 1 辆车 |
| 文字语言 | 招牌、路面字 | 日文 |
| 观看方式 | 只在网页转 / 要视频 | 网页 |

## 4. 关卡

需求卡 → 画风卡确认（给 v9 截图做参照）→ 元素清单与布局草图（俯视示意）→ 草稿 → 评委循环 → 归档。跳过分镜联系表（没有时间线）；要转台视频时再加镜头路径确认。

## 5. 评审

- 评委：美术总监（构图、光、氛围、叙事、模型感）+ 工艺评委（建模、材质、描边、倒影、性能、有没有穿帮）。
- 通过线：两位都 ≥ 80，或 5 轮，或用户喊停。用户意见优先于评委。
- 必截视角：默认主视角、正面、转角、小巷、低机位，各一张，固定相机参数（网页加 `?shot` 后可从 `window.__dio` 控制相机）。

## 6. 起手文件

- 起始代码：`works/rainy-corner-diorama/index.html`（含渲染管线、描边、倒影、雨、底座、自适应机位，换场景只换建模部分）。
- 依赖：cdnjs three r128 + jsdelivr `three@0.128.0/examples/js/*`。

## 7. 已知坑

| 现象 | 原因 | 解法 |
|---|---|---|
| 横条纹、边缘波浪 | 16 位深度渲染目标 + 描边外壳 | `logarithmicDepthBuffer`，自定义着色器加 logdepth 片段 |
| 画面发灰、体积拍扁 | 环境光太亮、全局亮 | 压环境光，用聚光做光池，调色加高光肩部 |
| 水洼像贴纸或黑洞 | 倒影太清、太暗或边缘硬 | 菲涅尔 + 天空底色 + 去饱和 + 噪声边缘 |
| 截图时相机乱跳 | 自动化的指针事件触发了 OrbitControls | 截图时关 controls，用 `?shot` |
| 本地 file:// 打不开 | 浏览器拦截 | `python3 -m http.server` |
| 圆角盒贴图糊 | r128 RoundedBoxGeometry UV 坍缩 | 按面重写平面 UV |
