一条片子怎么做出来

  1. 追问：场景、人物、情绪、结构、声音、禁忌，以及视频类型、目标级别和评审标准。
  2. 画风：从总目录和样片墙挑，写成数值风格卡，出 1–3 张风格帧确认。
  3. 分镜联系表确认后才生产；大任务按职责分给多个 agent 并行。
  4. 独立评委按你确认的标准卡逐条判定，只改不通过的项。
  5. 归档作品、写复盘，能复用的路子沉淀成方案。
