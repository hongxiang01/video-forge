# 评审：美术总监｜《AI 到底该怎么用》v2（第 2 轮复评）

评审依据：成片 ai-howto_v2.mp4（225.6s）、v2 的 3 张联系表，另抽 40 帧（judge_art/ 下 v*.jpg、w*.jpg，拼图 E/F/G.jpg）。重点抽了转场附近相隔 0.6s 的成对帧。
标准与维度和 v1 相同，评分按国际动画/动态设计奖的口径。文中秒数全部按 v2 时间轴。

## 1. 总分：66 / 100（v1：58，+8）

## 2. v1 五个问题逐条核对

| v1 问题 | 结论 | 依据帧 |

| ① 中段丢了流水线，退化成 PPT | **部分解决** | 已解决：4 张口号卡都改成流水线上方的吊牌（75.1s、99.5s、120.7s、175.8s），毛奇段改成沙盘桌（78.8s、82.5s），PDCA 改成环形传送带（149.1s、152s）。未解决：METR 段仍是柱状图（179.6–190.8s），只是加了外框和一只秒表；86.2s 的"命令/目标/为什么"仍是一张文档卡；章节标题"03 人站在哪"（169.3s）还是空白纸上的纯文字 |

| ③ 镜头不动，转场靠淡化 | **部分解决** | 已解决：有了推拉（1.6s→3.8s→6.0s、198.1s 推近、219.8s 特写），部分转场改成硬切（98.0s→98.6s）。未解决：63.8s「02 四条交代方法」半透明叠在上一镜的人物上；210.5s→211.5s 放大的工单残影「画一只表/指针/给谁看」叠在新一镜上，重影和 v1 的 172s 是同一类问题；全片还没有一次"跟着表横移进下一个工位"的元素承接转场 |
| ④ 字号太小、主体偏小偏上 | **部分解决** | 已解决：开头工单字号明显加大（0.0s 约 40px 以上），关键词吊牌约 50px，地板带收窄。未解决：草稿/配图标签（109.6s）、PDCA 的 计划/执行/改进/检查 灰框（149.1s）、来源角标、章节进度条文字仍然偏小、偏淡；114.6s 的"方案"卡里面只有空线，没有内容 |

一句话：5 条都动了，没有一条彻底解决，最大的进步是"吊牌取代口号卡"和"色板回正"。

## 3. v2 现在最影响分数的 5 个问题（按严重程度排）

### ① METR 段仍是柱状图，而且推镜头把标签切掉了
- **在哪**：179.6–190.8s。187.1s 推近时，左侧的"事前预计/事后感觉"被画框切成"计 / 觉"；190.8s 的「只有结果算数」是灰字压在米色地板带上，对比度很低，像水印。
- **为什么**：这是第 3 章的论据核心，也是全片唯一一段还在"读图表"的画面，PPT 感集中在这里。推镜头还把读图需要的标签切掉了，图表本身都没讲清楚。
- **怎么改**：
  - 把柱状图换成两只钟：程序员头顶的"心理钟"转得飞快（+24%、+20%），墙上的真实挂钟走得更多（−19%），两只钟并排定格后各自打标注。钟是全片母题，正好接得上。
  - 如果必须保留柱状图：取消推镜头，或者推到右侧数值为止，不能切掉左侧标签。「只有结果算数」改成墨色 900 字重、≥72px，放回纸面区域，再用橙红手绘圈圈住。

### ② 结尾删掉了表，最后一拍只剩文字卡
- **在哪**：219.8s 的 4:30 特写做得好；但 222s 起整屏换成「模型决定上限 / 你决定结果」两行字加橙圈，表不见了，一直到 225.6s 结束。
- **为什么**：全片的承诺是"回到那只表，指针这次指对了"。最后 3.6 秒却回到"空白纸 + 圈口号"，正是 v1 刚去掉的那种口号卡。观众最后记住的是一句话，不是一个画面。
- **怎么改**：保留 219.8s 那只停在 4:30 的表，居中放大到画面高度的 45%，周围的流水线淡到 20%。两行字放在表的下方，「你决定结果」的橙圈和表的秒针最后一跳同帧完成，再接最后一声滴答，定格。

### ③ 转场里还有两处叠化重影
- **在哪**：63.8s，「02 四条交代方法」半透明叠在上一镜的三个剪影和思考泡上；210.5s，放大的工单残影「画一只表 / 指针 / 给谁看 / 感觉 / 不能错」压在新一镜的流水线上。
- **为什么**：两处都在章节衔接点上，纸本画风靠清晰的墨线成立，一出现半透明的两层画面，质感立刻掉下来。
- **怎么改**：
  - 63.8s：章节标题改成吊牌，从画外降下来挂在流水线上方；上一镜先硬切或用横移离场，不要和标题叠在一起。
  - 210.5s：改成从 SC16 那张工单直接推镜头进去，让工单占满画面（元素承接），再拉出到 SC17。全程只有一层画面。

### ④ 推镜头切边，场景里有空道具
- **在哪**：
  - 切边：1.6s 工单卡右边缘被画框切掉；198.1s「出厂」箱被切成「出」；219.8s 右侧清单卡只露出一半。
  - 空道具：98.6s 和 99.5s 传送带上有两个空白方块，什么也不代表；114.6s「方案」卡只有空线，没有内容。
- **为什么**：推镜头本身是进步，但没有做构图安全区，关键元素顶在画框边上，看起来像没对准。空方块和空卡是"摆了东西但没想好意思"，评委会读成没做完。
- **怎么改**：每个推镜头的终点构图都单独检查，关键元素离画框边 ≥80px。219.8s 要么把清单完整收进画面，要么彻底出画。99.5s 的两个方块换成本条原则的实物，比如"草稿"和"删文件"两张票据，正好为后面的单/双向门做铺垫。"方案"卡写上两行真内容（例如"删 3 个文件 / 待确认"），或者直接删掉这张卡。

### ⑤ 开头仍不是特写，10:10 揭晓还是太小；208.6s 压暗还在
- **在哪**：0–8.2s 一直是中景车间，8.2s 揭晓 10:10 时那只表约占画宽 9%。208.6s 整屏灰褐色。
- **为什么**：抖音前 3 秒决定观众留不留下来，全片最好的悬念需要大画面。整屏压暗跟"无光照的纸本"冲突，画面发脏。
- **怎么改**：
  - 开头：0–1.5s 给表盘特写（占画面 60%），机械臂的夹爪伸进画面装指针；8.2s 揭晓时再推回特写，10:10 加"✕"占半屏；车间全景放在 S02 用拉镜头揭示。现在的拉镜头可以保留，只是起点改成特写。
  - 208.6s：不要整屏压暗，改成三台机械臂褪成 #9A8F7E 线稿，三个人和脚下的橙红点保持满色。

## 4. 做得好、不要改的地方
- **流水线上方的吊牌（75.1s、99.5s、120.7s、175.8s）**：标题信息变成场景里的实物，这一轮最大的改进，保留。
- **毛奇沙盘（78.8–86.2s）**：箭头撞上"敌军主力"后折返，比 v1 的文档框好得多。
- **PDCA 环形传送带（149.1–152s）**：结构对，"循环"这个概念被做成了实物。建议环上跑一只表，每过一圈改一笔，让它真正动起来。
- **10:10 笑脸（18.1s）、弹簧小碟（129.3–133.6s）、单/双向门（104.5–114.6s）、"最常见"填空（30.6s）、三人站位（198–204s）**：仍是全片最好的几镜，不要动。
- **219.8s 的 4:30 特写**：v1 欠的回收这次给到了，构图有力量。问题只是它后面又接了一张文字卡。
- **墨色对勾**：色板纪律回到了单一橙红强调。

## 5. 能不能获奖：3 / 10（v1：2）
理由：世界观已经立住了，吊牌、沙盘、环形线说明方向对了；但 METR 图表、结尾文字卡、两处叠化重影、推镜切边这些执行层面的瑕疵仍然一眼可见。距离"每一帧都在搭一个世界并且会动"还差一轮专门打磨镜头和转场的工作。
