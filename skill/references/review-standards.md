# 评审标准库（默认检查项）

> 这里是各类型的**基础**检查项。每种类型 / 时长档在 `genres/<卡>.md` 第 6 节还有自己的校验逻辑（含可脚本测的阈值、对本表的升级或收紧），定评审标准卡时两边一起列给用户。

用法：追问阶段先请用户选类型（可以多选），把对应类型的检查项和「通用」项列给用户，请用户：
① 删掉不在乎的；② 把最在乎的 3–5 条标为**必须**，其余标为**加分**；③ 补充自己的标准，用户原话照录；④ 定下一票否决项。
整理成「评审标准卡」，用户确认后才能开工。这里只是起点，**最终以用户确认的标准卡为准**。

写法要求：每一条都要能在画面里找到证据，或者能用脚本量出来。模糊的词（"高级""有感觉"）不能直接当检查项，先请用户换成具体画面。
标注说明：【美】归美术评委，【工】归工艺评委，【量】表示可以用脚本测。

## 通用（所有类型默认带上）

| 编号 | 检查项 | 默认 |
|---|---|---|
| G1 | 【工】全片没有闪烁、跳帧、残影、双影（镜头切换处连抽 3 帧查） | 必须 |
| G2 | 【工】文字没有错字，不压线，不越出画面，不进平台遮挡区（如抖音右侧按钮栏、底部文案区） | 必须 |
| G3 | 【工】手机上看得清：1920 宽画布上，正文 ≥36px，关键词 ≥84px，标注 ≥40px | 必须 |
| G4 | 【工】【量】响度在平台建议范围内（抖音约 -14 到 -16 LUFS），真峰值 ≤ -1 dBTP，人声段配乐低于人声 ≥10dB | 加分 |
| G5 | 【美】全片只用风格卡里的颜色，强调色每个镜头只有 1 个重点 | 必须 |
| G6 | 【美】需求卡里用户原话写的禁区，一条都没碰 | 一票否决 |
| G7 | 【工】【量】没有超过 3 秒的完全静止段（片尾定格除外） | 加分 |

## 科普 / 知识讲解

核心问题：观众看完能不能用自己的话复述主题？

| 编号 | 检查项 | 默认 |
|---|---|---|
| K1 | 【美】第 0 帧就有主体（不是空屏或纯标题），前 3 秒内抛出问题或反常识的点 | 必须 |
| K2 | 【美】每句口播都有对应的画面动作，不是只把字贴上去（逐句对照时间轴，列出只有文字的句子） | 必须 |
| K3 | 【工】关键词、数字出现的时间，落在口播说到它的 ±6 帧内 | 必须 |
| K4 | 【美】画面上的数字、人名、年份都有出处（对照调研或事实清单） | 必须 |
| K5 | 【美】全片有一个贯穿的比喻或场景，各章之间有承接（章首第一个镜头沿用上一章的元素） | 加分 |
| K6 | 【美】每章有且只有一个高光时刻（论点句配主角大画面） | 加分 |
| K7 | 【美】结尾回扣开头的问题，不是罗列总结 | 加分 |
| K8 | 【美】没有连续 2 个以上"空白纸 + 一句口号"式的镜头（PPT 感） | 加分 |
| K9 | 【工】【量】章节切换、关键词出现、高光时刻落在配乐拍点或小节线上（±2 帧，对照 BPM 网格） | 加分 |
| K10 | 【美】和同类热门视频放在一起能一眼认出来：不是"暗色背景 + 发光线条 + 粒子"的默认样子（除非用户点名要） | 加分 |
| K11 | 【美】结构有张力：观众在前 1/3 就带着一个问题往下看，后面的段落在逐步回答它（不是可随意调换顺序的并列清单） | 加分 |
| K12 | 【美】第 1 分钟内有一次小揭晓；之后每 60–90 秒有一次再钩（新问题 / 反转 / 揭晓），列出每个点的秒数 | 加分 |
| K13 | 【美】至少一处信息密度高、值得暂停回看的画面 | 加分 |

## 叙事动画短片（有角色、有故事）

核心问题：把声音关掉，只看画面，能不能讲清这个故事？

| 编号 | 检查项 | 默认 |
|---|---|---|
| D1 | 【美】静音看画面，能说出谁、想要什么、遇到什么阻碍、结果如何 | 必须 |
| D2 | 【美】角色在各镜头里外形、配色、比例一致（设定卡逐项对照） | 必须 |
| D3 | 【美】每个镜头只有一个视觉焦点，焦点切换有引导（视线、运动、光） | 必须 |
| D4 | 【工】角色动作有预备和收尾，不是匀速滑动；没有穿模 | 必须 |
| D5 | 【美】情绪曲线和需求卡一致（开头、中段、结尾各抽一帧对照） | 加分 |
| D6 | 【美】镜头语言有变化：景别至少三种，至少一次有意的运镜 | 加分 |
| D7 | 【工】口型或动作和台词、音效对得上（±3 帧） | 加分 |

|---|---|---|
| M1 | 【工】【量】主要画面变化落在拍点或小节线上（±2 帧，对照节拍表） | 必须 |
| M2 | 【美】每句歌词都有对应画面，不是通用的氛围素材循环 | 必须 |
| M3 | 【工】【量】歌词字幕逐字对齐（±3 帧） | 必须 |
| M4 | 【美】副歌和主歌的画面能量明显不同（运动量、色彩、景别） | 加分 |
| M5 | 【美】抽鼓、静默段画面也跟着收 | 加分 |
| M6 | 【美】有一个贯穿全曲的视觉母题 | 加分 |

## 特效 / 视觉奇观片

核心问题：有没有一个让人想截图、想重看的瞬间，而且它可信？

| 编号 | 检查项 | 默认 |
|---|---|---|
| F1 | 【美】至少有 1 个"高光帧"：截出来单独看就成立 | 必须 |
| F2 | 【工】运动符合物理直觉：有重量、惯性、加减速；粒子和流体没有穿帮的断层 | 必须 |
| F3 | 【工】光照方向、阴影、反射在同一个镜头里一致 | 必须 |
| F4 | 【工】【量】没有色带、马赛克、压缩伪影（暗部和渐变区放大查看） | 必须 |
| F5 | 【美】特效服务于情绪或叙事，不是堆在一起炫技（每个特效写出它表达什么） | 加分 |
| F6 | 【美】节奏有张弛：大特效前有铺垫和蓄力 | 加分 |

## 画风 / 氛围短片（无故事，重情绪与美感）

核心问题：截任意一帧，能不能一眼认出这种画风、感觉到这种情绪？

| 编号 | 检查项 | 默认 |
|---|---|---|
| A1 | 【美】随机抽 10 帧，每帧都符合风格卡的数值（色板、线宽、光比） | 必须 |
| A2 | 【美】需求卡上的情绪关键词，每段都有对应的画面证据（光、色、天气、动作） | 必须 |
| A3 | 【美】构图有层次：前景、中景、远景至少两层，有留白 | 加分 |
| A4 | 【工】动态克制、连续：没有突兀的加速和跳切 | 加分 |
| A5 | 【美】有记忆点：一个独特的物件、光效或动作 | 加分 |

| S1 | 【工】任意角度没有穿模、破面、空洞（转一圈每 45° 截图） | 必须 |
| S2 | 【工】【量】交互流畅：帧率 ≥ 50fps，拖拽没有卡顿 | 必须 |
| S3 | 【美】主视角构图成立，有主体、有故事线索 | 必须 |

## 新类型

用户的视频不属于以上任何一类时：先问用户这个类型的"核心问题"，也就是"观众看完应该怎样"，再和用户一起写 5–8 条检查项。做完后把它补进本文件。
