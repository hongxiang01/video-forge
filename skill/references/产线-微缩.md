# 产线：三维微缩场景（three.js）

方案全文：`~/style-studio/方案/三渲二微缩场景.md`（适用范围、追问追加、关卡、评审视角、已知坑）。
画风卡：`~/style-studio/我的画风/三渲二雨夜微缩/STYLE.md`（数值）。
起手代码：`~/style-studio/作品/雨夜便利店街角/index.html`（v9）。复制到新作品目录，保留渲染管线、描边、倒影、雨、底座、机位部分，替换建模部分。

## 步骤

1. 需求卡（必须拿到「必须出现的元素清单」，逐条编号）。
2. 画风卡确认：附 v9 截图（`~/style-studio/作品/雨夜便利店街角/截图/`）当参照，问清和它比要改什么（时间、天气、色调）。
3. 布局草图：俯视示意（文字或简单 SVG），标出主体、街道、每个编号元素的位置，用户确认。
4. 风格帧：先做一个角落定光，用户确认「亮度、对比、色调」再铺开（雨夜便利店就是光到第 3 轮才对）。
5. 草稿：全部元素到位。
6. 评委循环：本地起服务 `python3 -m http.server`，加 `?shot` 进截图模式，固定 5 个视角截图。Playwright MCP 浏览器被占用时，用 lemo 装好的 headless Chrome：`require('~/mv-xue/lemo-opuscar/node_modules/playwright-core').chromium`。
7. 发布：用 Artifact 工具发布 HTML（只能引用 cdnjs / jsdelivr / unpkg 的脚本，不能引外部图片和媒体）。
8. 归档到 `~/style-studio/作品/<作品名>/`，更新方案文件第 8 节。

## 要转台视频时

追加镜头路径确认（起止角度、时长、速度曲线），用 headless Chrome 逐帧截图 + `ffmpeg` 合成。
