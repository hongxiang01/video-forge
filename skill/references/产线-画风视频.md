# 产线：画风视频（lemo-opuscar）

用 lemo-opuscar 的 66 种画风之一，给用户自己的主题做一支 30–90 秒的代码短片。

## 库与环境

- 库：`LIB=~/mv-xue/lemo-opuscar`（稀疏克隆，依赖已装：`node_modules`、`.venv`、headless Chrome）。
- 检查/补装：`cd $LIB && env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY sh plugin/skills/lemo-opuscar/scripts/setup.sh deps`；要配音加 `voice`（约 0.55 GB），要乐器采样加 `music`，用到才装。
- 拉某个画风：`git -C $LIB sparse-checkout add styles/<slug>`（git 同样绕开代理，`-c http.proxy=`）。只有 `STYLE.md` 时也够写风格卡；demo 源码用 `sh plugin/skills/lemo-opuscar/scripts/setup.sh demo <slug>`，**写完 TREATMENT.md 之后**才看。
- 库的规则照搬：`$LIB/AGENTS.md`（风格不变式、Treatment first、不在 `styles/` 里做、不改 `core/`）、`$LIB/DIRECTOR.md`（导演）、`$LIB/TECHNIQUE.md`（配音、配乐、混音）、`$LIB/core/README.md`（命令）。
- 生产目录：`~/video-forge/films/<name>/`（`<name>` 用小写英文和连字符，lemo 的服务路径对中文不友好）。归档时在 `~/video-forge/作品/<中文作品名>/README.md` 指过去。

## 和 lemo 自带流程的差别（以本 skill 为准）

| lemo 默认 | 这里 |
|---|---|
| 只问一轮，其余自己补默认值 | 按 `追问清单.md` 问到必填项齐 |
| 分镜默认不确认 | 分镜联系表默认确认 |
| 自检后交付（DIRECTOR.md §11） | 自检 + 独立评委循环（`评审.md`） |
| 没有新手引导 | 先给样片墙和内容点子（`画风推荐.md`） |

## 铁规矩：先出片，再精修

2026-11-04《最后一碗面》的教训：Treatment 用了 2 小时，3 张静帧磨了 4 轮、4 个多小时，13 个镜头里只有 3 个有画面，一整晚没出过一秒视频，用户问「是不是整个流程有问题」。正常动画的顺序是先做粗剪（动态分镜 + 临时声音）看整片节奏，再逐个镜头精修。所以：

- **开工前报时间表**：每一步预计多久、第一版整片什么时候能看。某一步超时就停下来跟用户说，不闷头继续修。
- **风格帧只做定调**：1–2 张，一轮自动修正，用户点头就进下一步，不追奖级分数。
- **第一版整片在开工后 1–2 小时内出来**：搭好整片时间线（每个镜头一个模块，缺的先画占位卡，整片随时能出），所有镜头按「构图、主体、关键动作对」的粗剪级并行画完，配临时声音和字幕，出能播放的 MP4。
- **之后每一轮都交整片**：按用户看片的意见挑镜头精修，改完重出整片；评委看整片，不再给单张静帧打分。

## 步骤

1. **需求卡**（本 skill 步骤 1）。
2. **画风**：读 `$LIB/styles/<slug>/STYLE.md`，写风格卡贴给用户确认。
3. **TREATMENT.md**：三种结构候选 + 选择理由（`$LIB/DIRECTOR.md` §4），贴给用户确认。主题不能往样片的故事上靠。一版初稿 + 一次检查即可，不跑多轮评委。
4. **风格帧定调**：`cd $LIB && node core/render/still.mjs "<project>" <秒…>` 出 1–2 张，对照 `STYLE.md` 检查，给用户看。
5. **设定卡**（有人物/地点时）。
6. **粗剪**：整片时间线 + 全部镜头粗剪级 + 临时声音 + 字幕 → 第一版 MP4（`node core/render/video.mjs`，`sh core/render/mux.sh`）。分镜确认改成看这一版。
7. **精修轮**：按用户意见挑镜头精修，每轮重出整片；配音 → 配音检查 → 正式配乐 → 混音（`$LIB/TECHNIQUE.md`）在这一段完成。
8. **评委循环**：给评委整片 + 联系表（`评审.md`）。
9. **交付与归档**：成片在生产目录，`作品/` 下写 README 指向它，附需求卡、风格卡、TREATMENT、评分记录。
