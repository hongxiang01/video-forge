# 追问清单

规则：每轮 ≤ 4 个问题（`AskUserQuestion`），选项写成具体画面，推荐项放第一个并标「（推荐）」。用户已经说清的项不再问。每轮后贴需求卡。

## 必填（没齐不开工）

| 项 | 要问到什么程度 | 模糊回答的追法 |
|---|---|---|
| 用途与平台 | 发哪里（抖音/B 站/视频号/展示页/自己看）、给谁看 | 「给朋友看」→ 横屏还是竖屏？手机看还是电脑看？ |
| 时长与画幅 | 秒数、16:9 / 9:16 / 1:1 | 给 30 / 60 / 90 秒三档 |
| 主题一句话 | 观众看完记住什么（一句话能说清） | 「讲讲 XX」→ 给 3 个不同角度的一句话让选 |
| 情绪 | 开头、中段、结尾各是什么感觉 | 「温馨」→ 给画面：深夜厨房一盏灯 / 午后阳台晒被子 / 雨天车窗 |
| 人物 | 有没有人；几个；年龄、外形、穿着；在做什么；是主角还是背景 | 代码画的人物不演戏，提前说明；可选「只出现背影/剪影/远景小人」 |
| 场景 | 地点、时间（季节、几点）、天气、室内外、几个场景 | 「城市」→ 哪种城市：老街 / 新区高楼 / 海边小城 |
| 结构 | 怎么开头、中间几段、怎么结尾；有无反转 | 给三种结构让选（产线文件里有对应模板） |
| 声音 | 配音（谁的声音、语速）、音乐（风格、有无现成）、音效 | 「有点氛围」→ 给 2–3 种具体乐器组合 |
| 文字 | 语言、字幕有无、标题、必须出现的名字/数字/口号 | |
| 素材 | 用户自己的 mp3、LRC、照片、logo、字体、数据 | |
| 禁忌 | 绝对不要的东西（颜色、元素、风格、情绪） | 主动举例：太亮？太花？卡通化？AI 感？ |
| 目标级别 | 想做到什么程度：① 自己看 / 发朋友圈；② 平台热门（抖音、B 站同类视频的前列）；③ 行业交付（品牌、广告公司能直接用）；④ 大奖级（如格莱美最佳 MV、安妮奖、奥斯卡动画短片）。也可以直接点名一部作品（「像《蜘蛛侠：纵横宇宙》那样」） | 点名作品时，请用户说出最想学它的 3 个地方，翻译成画面上看得到的检查项写进评审标准卡（不拿"像不像这部片"打分）。级别越高，加分项转成必须项越多、评审轮次越多（①1 轮 ②2 轮 ③④3 轮）。照实告诉用户这条产线的上限：代码绘制 + TTS 配音通常到 ②；要冲 ③④ 需要真人配音、原创配乐、更长制作周期 |
| 视频类型与评审标准 | 属于哪一类（科普、叙事动画、MV、特效、画风氛围、微缩交互、广告，可多选或新类型）；从 `评审标准库.md` 该类型的检查项里勾出最在乎的 3–5 条作为必须项，其余作为加分项，再补用户自己的标准、定一票否决项 → 写成「评审标准卡」请用户确认 | 用户说「你定」：按类型给默认必须项，标「默认，可改」；模糊标准（「要高级」）请用户换成画面上能看到的东西 |

## 按产线追加

- **画风视频**：画风是否已定；是否借用样片里的某种动作/镜头（只借语法不借内容）。
- **MV**：见 `产线-MV.md` 的「要用户提供的文件」与解读卡。
- **科普**：目标观众知识水平；核心论点和 3 个支撑事实；数据来源。
- **微缩**：见 `~/style-studio/方案/三渲二微缩场景.md` 第 3 节。

## 用户说「你定」时

不要跳过，把默认值写具体（例：「竖屏 9:16、45 秒、女声普通话、语速 0.95、钢琴+弦乐垫底」）写进需求卡，标「默认，可改」。

## 什么时候停止追问

必填项都有具体值 + 用户确认了需求卡。不因为「问太多」而提前开工；但同一项不要问第三遍，第二遍还模糊就给默认值并标出来。
