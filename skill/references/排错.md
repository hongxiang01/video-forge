# 排错

| 现象 | 原因 | 解法 |
|---|---|---|
| `npm install`、`git clone`、下载极慢或中途失败 | shell 里设置的 http(s)_proxy 代理只有十几 KB/s | `env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY <命令>`；`curl --noproxy '*'`；`git -c http.proxy= -c https.proxy=` |
| `grep` 报 `claude native binary not installed` | shell 里的 `grep` 是 Claude Code 注入的函数 | 用 `/usr/bin/grep`；同时说明 Claude Code 本体坏了，按 `~/.claude/projects/-Users-xiaodao/memory/npm-proxy-slow.md` 修 |
| lemo 渲染找不到浏览器 | headless Chrome 没装 | 在库根目录跑 `setup.sh deps`（绕开代理） |
| lemo 的 `setup.sh demo` 报错 | 稀疏克隆是 cone 模式 | 改用 `git -C ~/mv-xue/lemo-opuscar sparse-checkout add styles/<slug>` |
| Playwright MCP 报 `Browser is already in use` | 别的会话占着 MCP 浏览器 | 用 lemo 的 `node_modules/playwright-core` 自己写截图脚本 |
| 本地 HTML 用 `file://` 打不开或截图空白 | 浏览器拦截本地文件 | `python3 -m http.server <端口>`，用完关掉 |
| Artifact 里视频、图片不显示 | Artifact 的 CSP 拦截外部媒体 | 图片转 data URI；视频只放链接 |
| 三维场景横条纹、描边波浪 | 深度精度不够 | 见 `~/style-studio/方案/三渲二微缩场景.md` 第 7 节 |
| 画面整体发灰、太亮、没体积 | 环境光太强 | 压环境光，用聚光做光池，调色压高光 |
| 子 agent 每隔整 10 分钟发一次请求、一直没有回复 | 单次请求超过 10 分钟被掐断后重试：一次回复要输出整篇长文，或动笔前构思太久（一次实测 5 万多 token、9 分 16 秒） | 看门狗 `scripts/watch_agents.py` 会自动报出来。停掉，按 `分工.md` 拆成骨架 → 分节 → 场记；正文分节写进文件，只交回路径。不要靠降低思考强度。兜底：`API_TIMEOUT_MS` 已设为 30 分钟 |
| 文件在临时目录里丢了 | scratchpad 重启会清 | 一开始就把生产目录建在 `~/style-studio/films/` 或项目仓库里 |
