# 产线：科普 / 信息视频（Remotion）

项目：`~/remotion-effects`（Remotion 4，特效注册在 `effects/`，时间轴 JSON 用 `at()` 锚点）。参考作品：王朝 300 年 `effects/dynasty-300/`，上游脚本 `pipeline/dynasty-300/`（README 有每个脚本的用法）。改代码前按项目约定和全局规则先 `maestro search` / `maestro load`。

## 适合

讲清一件事：历史、地理、数据、原理、流程。不适合有人物情绪的故事（走画风视频或 MV）。画风可以借 lemo 的信息类画风（白板、黑板、等距信息图、数据叙事、卫星简报）的规则。

## 追问追加

- 观众是谁、懂多少；
- 核心论点一句话 + 3 个支撑事实；每个事实的来源；
- 要不要地图、图表、时间线；
- 配音还是纯字幕。

## 步骤

1. 需求卡 → `pipeline/<作品>/brief.json`。
2. 画风卡 + 风格帧。
3. 文案：逐句写进 `script.json`，**每句都要有对应画面**（地图在动、数字在变、对比在发生），不许整屏文字。
4. 分镜：`storyboard.json`（每句：画面、动画、时长），出静帧联系表（`review/stills.cjs` + `review/sheet.py`），用户确认。
5. 配音（`tts.py`，edge-tts）→ 逐句时长 → 时间轴按配音锚定 → 配乐混音（`build_audio.py`）。
6. 动画实现与渲染。
7. 评委循环（`review.md`），静帧联系表 + 成片。
8. 归档：脚本留在 `pipeline/<作品>/`，`~/video-forge/works/` 下写 README 指过去。

## 结构模板（追问"结构"时给用户选）

1. **谜题式**（2026 抖音 Vibe 知识爆款《信息论》的结构）：开头抛一个悬念或反常识问题，中间每段给一条线索，观众带着疑问往前走，末段让零散线索汇合，答案"啪"地成形。适合讲一个概念、一条原理。
2. **清单式**：钩子 + N 条要点 + 收束。最容易做，也最容易变成 PPT。用的话每条要点都要有自己的场景和动作，各条之间要有递进（不能随便调换顺序），不要并列罗列。
3. **旅程式**：一个主角或一件物品从起点走到终点（一条流水线、一封信的旅程），每一站讲一个点。适合讲流程和系统。

《AI 到底该怎么用》用的是清单式，评委批评它中段像 PPT。下次讲方法论类主题，先考虑能不能改成谜题式：比如"为什么 AI 总画 10:10"作为谜题，四条原则作为四条线索，最后汇合成"人站在哪"。

## 差异化（2026-11 平台现状）

- 2026 年起抖音、B 站知识区涌现大量 AI 生成的"Vibe 知识"视频，做法和我们一样（大模型写代码出动画）。它们的视觉高度同质：**暗色背景 + 发光线条 + 粒子特效 + 电子乐卡点**，刷到第 10 条就分不清谁是谁。
- 所以默认**不用**这套视觉，除非用户明确要。画风从总目录挑有辨识度的（纸本、版画、手绘、等距插画……），风格帧阶段把候选和"暗色发光"做一次并排对比给用户看。
- 我们能赢的地方：**严谨**（有调研和出处，热潮里普遍被质疑严谨性）、**有自己的画风**、**有观点**（不是复述百科）。

## 写稿

- 稿子是最慢、最值钱的一环（Kurzgesagt 一条片约 1200 小时，最卡的是写稿，会反复重写）。配音前至少改出第 2 版：第 1 版写完后自己朗读一遍，把"念出来别扭""换成画面能省掉"的句子改掉，再给用户看。
- 全片用固定角色代表概念（Kurzgesagt 把免疫细胞画成士兵），角色定了就贯穿到底，不中途换比喻。

## 配乐和节奏

- 这类片子观众要的是"像看 MV 的愉悦感"：信息密度高、动效丝滑、节奏明快。配乐不是背景垫子：先定 BPM，把章节切换、关键词出现、高光时刻尽量卡在拍点或小节线上（huashu-art-motion 的 references/05-节奏与配乐.md 有 BPM 网格做法）。
- 安静的段落（思考、转折）配乐可以收，但要是有意的收，不是全程一个音量。
