# 卡片模板

卡片直接贴在对话里；确认后存进 `~/video-forge/作品/<作品名>/`。

## 需求卡

```
【需求卡】<作品名>（第 N 轮）
产线：画风视频 / MV / 科普 / 微缩        方案：<方案名或无>
用途/平台：            时长/画幅：
一句话主题：
情绪曲线：开头 → 中段 → 结尾
人物：
场景：
结构：
声音：配音 / 音乐 / 音效
文字：
素材：
禁区与硬要求（用户原话）：
未定：<列出还没定的项>          默认值：<标「默认，可改」>
```

## 评审标准卡（用户确认后才开工；评委只按它判）

```
【评审标准卡】<作品名>
视频类型：<科普 / 叙事动画 / MV / 特效 / 画风氛围 / 微缩交互 / 广告 / 新类型：…>
目标级别：<自己看 / 平台热门 / 行业交付 / 大奖级>；对标作品：<名字>，想学它的地方（已转成下表检查项）：<1. … 2. … 3. …>
核心问题：<观众看完应该怎样，一句话>
| 编号 | 检查项（能在画面里找到证据，或能用脚本测量） | 必须/加分 | 归属（美/工） | 来源（标准库编号 / 用户原话） |
一票否决：<用户原话>
发布条件：必须项全部通过 + 没有触犯一票否决项
评委判不了、交给用户判断的：<如音色、配乐是否好听>
```

```

不是什么：
色板：主色 #…  辅色 #…  暗部 #…  高光 #…
线/描边：粗细、颜色、哪些东西不描边
光：主光方向与色温、光比、曝光上限
材质/笔触：
字体与字幕：
镜头语法：允许的运镜、转场；禁止的
动态：帧率、缓动、哪些东西会动
声音：乐器、音色
本片的改动：<相对原画风改了什么，为什么>
```

## 分镜联系表

一张图 6–9 格（3×2 或 3×3），每格下方写：

| 格 | 时间 | 画面 | 镜头 | 声音/台词/歌词 | 情绪 |
|---|---|---|---|---|---|

联系表图片用真实绘制代码出静帧拼成（lemo 产线用 `core/render` 出帧，Remotion 用 `review/stills.cjs` + `review/sheet.py`）。
