# 类型卡：画风 / 氛围短片（无故事，重情绪与美感）

用法：追问阶段用户选了「画风氛围」后读这张卡。生产流程看 `../pipeline-style-film.md`；通用检查项和已有的 A1–A5 见 `../review-standards.md`，这里只引用编号。有故事、有转折的片子走 `narrative-short.md`。

数字标注：**[实测]** 来自本仓库或 vendor 文档量过的数；**[来源]** 附出处；**[经验值]** 是起点、待验证。

---

## 1. 定位与核心问题

**观众看完应该：截任意一帧都认得出这种画风、感到同一种情绪；看完愿意停留，或者让它再循环一遍。**（对应 A1、A2）

氛围片没有「谁想要什么」，它的骨架是**一个地方 + 一段时间里的一种变化**（光变了、雨下大了、天黑了）。这正好是代码绘制的强项：规则性的运动（雨、雾、光、水、风、粒子）、确定性的时间、无限精确的镜头。人物在这里本来就只是风景的一部分，小、远、剪影、简单循环（SKILL.md 铁规矩 7）不是妥协，而是这一类的常规做法（Lofi Girl、动态《清明上河图》都如此）。

## 2. 时长与画幅

| 项 | 短档（循环型） | 标准档 |
|---|---|---|
| 推荐时长 | 15–30 s，做成**无缝循环** | 45–90 s，默认 60 s |
| 适合 | 动态壁纸、片头、直播背景、单一场景单一情绪 | 一个地方的一段时间：黄昏到入夜、雨从小到大、一条街从醒到睡 |
| 镜头数 | 1（一镜到底） | 3–10 [经验值] |
| 平均镜头时长 ASL | = 全片 | 6–15 s [经验值：氛围片的镜头要长到观众「住进去」；对照叙事微短片的 3–4 s 慢 2–4 倍] |
| 情绪曲线 | 平：一种情绪贯穿，只靠循环里的小事件起伏 | 平—缓升—回落：开头建立 → 一个变化事件（全片 50–75% 处）→ 落定余韵 |
| 变化事件 | 0–1 个（循环里可以是一只猫跳上窗台） | 1–2 个，不要更多——多了就变成叙事片 |
| 帧率 | 30 或 60 fps [经验值：慢摇、慢漂在 24 fps 下容易抖（judder），氛围片大量慢运动，优先高帧率；风格卡指定 24 fps 的画风（如赛璐珞）照风格卡] | 同左 |

**横竖屏**：默认横屏 16:9 1920×1080（用户抖音作品固定横版，画面不加字）。氛围片的环境就是内容，横屏留得住天空和街景；循环型做手机壁纸时才考虑 9:16，并按竖构图重新布局（纵深、仰望、高楼、瀑布），不裁横版。

## 3. 结构模板

### 模板 A：一镜到底 + 一次变化（定机位、画一直活着）

出处：Lofi Girl（固定机位，女孩循环写字、偶尔看窗台上的猫，窗外天色随时间变）。

| 段 | 占比 | 做什么 |
|---|---|---|
| 建立 | 0–15% | 第 0 帧就是完整画面（不从黑场淡入超过 0.5 s）；主循环（雨、写字、灯闪）已经在动 |
| 住进去 | 15–55% | 镜头慢漂 1–4%/s，或完全不动；每 5–10 s 出现一个小母题事件（猫尾、车灯扫过、一片叶子落）[经验值] |
| 变化 | 55–75% | 一个事件改变整幅画：路灯亮起、雨变大、云散月出。光和色在 2–6 s 内过渡，不跳 |
| 余韵 | 75–100% | 新状态住一会儿；结尾定格或回到第 0 帧（循环） |

### 模板 B：同一地点，几个时刻（时间切片）

出处：动态《清明上河图》分白天、夜晚两版，同一长卷换光换人。

| 段 | 占比 | 做什么 |
|---|---|---|
| 时刻 1 | 0–30% | 例：午后，暖光，人多 |
| 时刻 2 | 30–60% | 例：黄昏，逆光，人往家走 |
| 时刻 3 | 60–90% | 例：入夜，窗灯一盏盏亮，人只剩剪影 |
| 收 | 90–100% | 最后一盏灯 / 最后一个声音 |

每个时刻用**同一构图或同一机位路径**，只改光、色、天气、人群密度。时刻之间用光过渡（天色推移 3–5 s）或画风自己的转场，不叠化。

### 模板 C：长卷横移（一条街、一条河）

出处：动态《清明上河图》（长卷 + 数百个各自循环的小人）；huashu `11-长卷穿越片.md`（相机只进不退、段与段的边界规则）。

| 段 | 占比 | 做什么 |
|---|---|---|
| 入卷 | 0–10% | 从卷首一个安静的角落开始，镜头起步慢 |
| 行进 | 10–85% | 匀速横移（或随音乐呼吸地变速）；每经过一段有一个「小站」：一个比周围更密的母题（码头、桥、灯笼铺），观众的眼睛在这里停 |
| 出卷 | 85–100% | 停下或拉远，见到卷的全貌一角 |

规则：相机位置单调，不倒带（huashu 07 第 38 条）；每个小人的循环用全片时间 t，不随段重启。

### 循环收尾（A、B 都可加）

做循环型时，最后 1–2 s 的所有循环相位回到第 0 帧状态；配乐长度 = 整数小节，循环点落在小节第一拍。

## 4. 视觉规范

**画风（A1 是底线）**：先出 1–3 张风格帧，其中一张是「签名镜头」（lemo `DIRECTOR.md` §5：无人物时三张风格帧）。风格卡里的色板、线宽、光比是全片的硬约束。

**构图层次**
- 前景 / 中景 / 远景至少三层（A3 要求两层，氛围片要多一层，因为视差是它主要的「运动」）[经验值]。
- 镜头动时三层按不同系数移动（视差，例：远景 0.25、中景 0.5–1.0、近景 1.8，《最后一碗面》S8 实测用过）。
- 留白：至少一块大面积安静区域（天空、水面、墙），给眼睛休息。
- 主体：每个镜头一个最亮/最饱和的点（G5：强调色每镜一个重点）。

**画一直是活的**
- 每幕 = 1 个主动作 + 2–4 个取自该画风母题的小循环（huashu 07 第 12 条，16 段实测运动面积 1.6–14%、无跳变）。
- 方向场、笔触随时间连续变化，不整屏按低帧率重洗（huashu 07 第 13 条：整屏 8fps 重洗被读成「画在闪」）。
- 滚动纹样的取模周期等于图案真实周期，否则回绕那一帧整片跳（07 第 14 条）。

**光与色**
- 一个主光源，色温写进风格卡；变化事件靠光完成（亮灯、日落、闪电、云影）。
- 避开「深蓝紫渐变 + 霓虹 + 发光粒子」这套 AI 默认样子（film_gate 蓝紫门：作者否掉的片子蓝紫帧占比 0.46–1.00，认可的 ≤ 0.10）。雨夜题材最容易踩，用暖窗光、钠灯黄、湿路面反光去平衡。

**镜头运动**
- 慢漂、匀速慢推 1–4%/s 作起点（`镜头语言.md`：这个数「没有认可片实测」，用在氛围镜头上没被否过——做完并排看）。
- 不用快推、砸入、甩镜（那是解说片和喜剧的语法）。
- 运镜要有变化：作者看莫奈 MV 的原话「运镜和转场都显得单调、干涩，缺乏多样性」——推、拉、横移、升降、焦点转移、固定至少用 3 种 [经验值]。

**转场**
画风自己的转场（雾漫过、雨帘擦过、墨晕开、光推移），或同构图换光。不用默认叠化（叠化在代码绘制里常出双影）。

**人物**
- 只做小、远、剪影、背影；全身 ≤ 1/6 画高 [经验值，比叙事片更小：人在这里是风景]。
- 只做能回到起始姿势的循环动作（写字、翻书、走过、撑伞站着）。Lofi Girl 试过「躺着」的姿势，因为太费时间而放弃，最终角色要回到起始位置——循环动作要选短的、闭合的。
- 人群用「多个小人各自简单循环」堆密度（动态《清明上河图》白天 691 人、夜晚 377 人），每个人的相位错开。
- 动物、车、船同理：剪影 + 循环。

## 5. 声音规范

| 项 | 规范 |
|---|---|
| 台词/旁白 | 默认**无**。用户坚持要一句话时，放在结尾、做成画内文字或标题，不压画面主体 |
| 配乐 | 配乐是主角之一。乐器来自画风的声音调色板（lemo §6，避开万能钢琴 + 弦乐）；BPM 慢（60–90 [经验值]）；变化事件落在小节第一拍 |
| 环境底 | 全程不断（雨、风、街、水），这是氛围片的「空气」；音量随镜头景别变化（远景更空、近景更近） |
| 音效 | 少而准：只给画面里的小事件配音（猫跳、灯亮、车过），对齐画面事件 ±3 帧（与 D7 同一阈值） |
| 何时静音 | 变化事件前可以抽掉配乐 0.5–2 s，只留环境底，然后让变化和第一个和弦一起进 [经验值，参照 lemo §6「静默后第一声最重要」] |
| 循环型 | 配乐长度 = 整数小节，首尾无缝；环境底首尾做等功率交叉（不让循环点「咔」一下） |
| 响度 | 积分 -14 到 -16 LUFS，真峰值 ≤ -1 dBTP（G4）。氛围片容易做得太轻：安静 ≠ 响度低，靠编配稀疏表现安静，母带仍到目标值 |
| 评委边界 | 评委只测量，好不好听由用户判（`review.md`） |

## 6. 校验逻辑

默认带上 G1–G7、A1–A5。下面是本卡新增的 A10–A19。「必须/加分」是建议默认值，最终以用户确认的评审标准卡为准。

| 编号 | 检查项 | 必须/加分 | 阈值或判据 | 怎么测 |
|---|---|---|---|---|
| A1 | 随机 10 帧都符合风格卡数值 | 必须 | 色板、线宽、光比逐项对照 | 抽帧 |
| A2 | 情绪关键词每段有画面证据 | 必须 | 每段列出光/色/天气/动作证据 | 抽帧 + 人判 |
| A10 | 【量】时长在档内 | 必须 | 循环型 15–30 s；标准档 45–90 s；或用户定的秒数 ±1 s | `ffprobe -show_entries format=duration` |
| A11 | 【量】画一直是活的 | 必须 | 没有超过 3 s 的完全静止（G7）；每个镜头运动面积参考 1.6–14%（huashu 07 第 12 条），低于 1% 去看是不是死画 [经验值] | `python3 ~/video-forge/vendor/video-talkcraft/scripts/motion_check.py 成片.mp4`（ffmpeg freezedetect，任意 0.8 s 窗不全静止）；运动面积用逐帧差 > 阈值的像素占比自算 |
| A12 | 【工】【量】没有跳变 | 必须 | 除有意剪切外，相邻帧差没有孤立尖峰（> 前后 1 s 中位数的 3 倍 [经验值]）；常见原因：纹样回绕、整屏重洗、相位重启 | 逐帧灰度差曲线，尖峰处连抽 3 帧 |
| A13 | 【美】有且只有 1–2 个变化事件 | 必须 | 写出事件秒数和手段（光/天气/时间）；事件前后各抽 1 帧，变化一眼可见 | 抽帧并排 |
| A14 | 【美】人物是风景 | 必须 | 人物全身 ≤ 1/6 画高或为剪影/背影；无正脸、无口型；只做闭合循环动作 | 每 2 s 抽 1 帧，挑出有人的帧并排看 |
| A15 | 【工】【量】不落入蓝紫 AI 样子 | 加分（用户点名夜蓝/赛博时改为说明理由） | film_gate 蓝紫帧占比 < 0.12（黄灯线），红灯线 0.30 | `uv run ~/video-forge/vendor/huashu-art-motion/scripts/film_gate.py 成片.mp4`（「快速运动帧占比」一项是在解说片上标定的，氛围片偏低是正常的，只看不拦） |
| A16 | 【美】视差层次 | 加分 | 至少三层，镜头动时三层位移速度不同（量三层上各一个点的屏幕位移） | 抽相隔 1 s 的两帧对比 |
| A17 | 【工】【量】循环无缝（循环型） | 必须（循环型） | 末帧 → 首帧的帧差 ≤ 片内相邻帧差的 95 分位；音频循环点无爆音（循环拼接处峰值不突变） | 把成片首尾拼两遍，查拼接处帧差和波形 |
| A18 | 【工】【量】声音对位 | 加分 | 每个有音效的小事件与画面 ±3 帧；变化事件落在小节第一拍 ±2 帧 | 对照事件表 / 起音检测 |
| A19 | 【美】至少 3 帧可单独成立 | 加分 | 挑出 3 帧作封面候选，每帧单独看构图成立、认得出画风（同 F1 的思路） | 人判 |

## 7. 提示词模板

### 7.1 Treatment（氛围片没有剧本，写「场景 + 时间 + 变化」）

```
你是氛围短片导演。为下面这支片写 TREATMENT，只用模板 {A 一镜到底 + 一次变化 / B 同一地点几个时刻 / C 长卷横移}。
需求卡：{路径}  风格卡：{路径}  画风规则：{STYLE.md}
时长 {秒数} s，{是否循环}，{横/竖} 屏，{fps} fps。情绪关键词：{用户原话}。
硬限制：无对白；人物只做小、远、剪影、闭合循环动作；不要写成有转折的故事。
输出：
1. 一句话：在哪里、什么时候、从什么状态变到什么状态
2. 场景分层表：前景 / 中景 / 远景各有什么，各自怎么动（每层一个母题循环，写周期秒数）
3. 变化事件（1–2 个）：秒数、手段（光/天气/时间）、过渡时长
4. 时间表：每段秒数区间、镜头（固定/慢漂/横移/升降，写速度 %/s 或 px/s）、光色
5. 声音表：环境底、音效（对应哪个画面事件）、配乐（BPM、乐器、哪里抽掉）
6. 签名镜头一张：哪一秒，为什么截图就成立
7. 避开：{用户禁忌}；不做深蓝紫渐变 + 霓虹 + 粒子的默认样子（除非用户点名）
```

### 7.2 分镜

```
按 TREATMENT 写 shots.md（氛围片镜头少，每镜写细）：
| 编号 | 秒数 | 机位与运镜（速度） | 三层各有什么、各自的循环（周期） | 这一镜最亮的一个点 | 人物（剪影/背影/无，≤1/6 画高） | 光色（色值引用风格卡） | 声音 | 进/出这一镜的转场方式（画风自己的语言） |
约束：运镜至少 3 种；不用快推、砸入、甩镜；不用默认叠化；所有循环用全片时间 t。
附 3–6 格联系表清单（循环型给 3 格：开头、中间、结尾=开头）。
```

### 7.3 构建 agent 要点

- 场景建成比画面大的世界画布，镜头 = 视口；笔触、线宽按屏幕像素定，推镜头时笔触不变粗（huashu `06-口播驱动的艺术短片.md` 第 3 条）。
- 每层一个独立的绘制函数和视差系数；母题循环写成 `f(t mod 周期)`，周期互为非整数比，避免几层同时「打拍子」。
- 区域色板：每个区域 7–8 色的色组，每一笔从组里抽色（huashu 07 第 6 条）。
- 光变化用插值的色指定（lit/shadow/line 各自插值），不在整张画上盖一层半透明滤镜。
- 循环型：先定循环周期，所有母题周期是它的整数分之一，最后一帧 = 第一帧。
- 先出整片低精度版本看节奏，再精修（`pipeline-style-film.md`「先出片」）。

### 7.4 评委关注点

```
本片类型：画风/氛围短片（{循环型/标准档}）。额外要求：
- 每 2 秒抽 1 帧后，再随机抽 10 帧逐帧对照风格卡（A1），列出不符合的数值。
- 找出变化事件，写出秒数和手段，事件前后各一帧并排（A13）。超过 2 个事件或看不出变化都判「部分」。
- 逐帧帧差找跳变（A12）；循环型把首尾拼起来看拼接处（A17）。
- 所有有人的帧并排看（A14）。
- 用 film_gate 量蓝紫占比（A15）；「快速运动帧占比」低不算问题。
- 用正常速度完整看一遍：哪一段让你觉得「死了」或「太吵」，给秒数。
```

## 9. 常见坑

1. **画是一张会动的壁纸，看 10 秒就够了**：全片没有变化事件。→ 至少一个光/天气/时间的变化（A13）。
2. **变化太多变成了故事**，又因为人物不能演，故事讲不清。→ 有转折就换到叙事类型卡。
3. **整屏重洗噪声导致画在闪**（huashu 07 第 13 条）。→ 笔触位置固定，方向场连续变化。
4. **纹样回绕跳帧**（07 第 14 条）。→ 取模周期 = 图案真实周期。
5. **雨夜 = 深蓝紫 + 霓虹**（film_gate 标定：被否的片子蓝紫占比 0.46–1.00）。→ 暖光平衡，或用户点名时写理由。
6. **24 fps 慢摇发抖**。→ 慢运动多的画风用 30/60 fps；必须 24 fps 时把横移速度降到每帧位移小于几像素，或加微量运动模糊 [经验值]。
7. **运镜单调**（莫奈 MV 原话「单调、干涩」）。→ 至少 3 种运镜，节奏跟音乐段落变。
8. **叠化转场出双影**（《AI 到底该怎么用》）。→ 画风自己的转场或同构图换光。
9. **循环拼接处「咔」一下**（画或声音）。→ 首尾帧差和音频拼接点都要量（A17）。
10. **风格帧磨太久**（《最后一碗面》4 小时磨 3 张）。→ 1–3 张定调，一轮修正，用户点头就出整片。
11. **太安静 = 响度太低**，上平台被拉高后底噪明显。→ 母带仍到 -14 到 -16 LUFS，安静靠编配。
