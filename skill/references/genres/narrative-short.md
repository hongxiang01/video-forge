# 类型卡：叙事动画短片（有角色、有故事）

用法：追问阶段用户选了「叙事动画」后读这张卡。它不替代产线文件（生产流程看 `../pipeline-style-film.md`），只补这一类片子**特有的**时长、结构、规范、校验和提示词。通用检查项和已有的 D1–D7 见 `../review-standards.md`，这里只引用编号、不重抄。

数字标注：**[实测]** 来自本仓库作品或 vendor 文档里量过的数；**[来源]** 附出处；**[经验值]** 是起点，做完和参考并排看，按结果改。

---

## 1. 定位与核心问题

**观众看完应该：关掉声音也能用一句话说出「谁想要什么、发生了什么变化、结果怎样」，并且带走一个画面。**（对应 D1）

这条产线的硬限制：画面全部由代码绘制（canvas / Remotion / three.js），**代码画的人物不演戏**——表情、手指、口型都会僵（SKILL.md 铁规矩 7；`vendor/huashu-art-motion/references/角色精细度.md`）。所以叙事动画在这里的打法是：**故事由镜头、光、物件、环境和剪辑讲，人物只负责「在场」。**

## 2. 时长与画幅

| 项 | 微短片 | 短片 |
|---|---|---|
| 推荐时长 | 30–60 s，默认 45 s | 2–5 min，**第一次做先定 2–3 min** |
| 适合 | 一个人、一个时刻、一个转折（最后一碗、一次告别、一次等待） | 一段时间、一个变化过程（几年、四季、一个规则被打破） |
| 镜头数 | 8–16 [实测：《最后一碗面》45 s / 13 镜] | 30–70 [经验值] |
| 平均镜头时长 ASL | 3–4 s [实测：同上 ASL 3.5 s，多数镜头 = 80 BPM 一小节 3.0 s；最长 9.0 s] | 3–6 s [经验值；参照：真人动作片 ASL 约 4 s、冒险片 5.1 s，[来源](https://stephenfollows.com/many-shots-average-movie/)] |
| 最长单镜 | ≤ 10 s（结尾定格可到 12 s） | ≤ 15 s，长镜头要标「有意长镜」并写理由 |
| 节拍/情绪曲线 | 单峰：钩子 → 铺陈 → 一个转折 → 余韵。转折落在 55–70% 处 [实测：《最后一碗面》转在 27–33 s / 45 s = 60–73%] | 三幕 + 中点：每 45–75 s 一次局势变化或新信息 [经验值，比科普 K12 的 60–90 s 略密，因为没有口播托底] |
| 静默 | ≥ 1 段真静默（≥ 0.75 s，一拍）在转折前后 | ≥ 2 段，在转折和情绪高点前（lemo `DIRECTOR.md` §6） |
| 台词/旁白量 | 0–4 句字幕旁白 | 0–12 句；超过就是在用字讲故事，回去改画面 |
| 帧率 | 24 fps（lemo 默认）；手和身体动作按 12 fps「一拍两格」[实测：《最后一碗面》] | 同左 |
| 制作成本提醒 | 一晚可出第一版整片（`pipeline-style-film.md`「先出片」） | lemo：超过 2–3 分钟时间和 token 成倍增加，开工前告诉用户；必须按 `division-of-labor.md` 先定 `skeleton.json` 再分组并行 |

60–120 s 之间是过渡档：按微短片的单峰结构，在铺陈段加一次「重复—变奏」（同一动作做第二遍，结果不同），不要硬套三幕。

**横竖屏**：默认横屏 16:9 1920×1080（用户的抖音作品固定横版，画面不加字，文案进标题和描述）。叙事动画靠大远景里的小人物和环境讲故事，竖屏会把环境裁掉；用户点名要竖屏时，构图改成纵向关系（上下楼、高窗、坠落、仰望），不要把横版构图居中裁切（`镜头语言.md` 第四节「竖屏放横版插图，先裁再摆」）。

## 3. 结构模板

追问「结构」一项时给这三种让用户选（Treatment 阶段仍按 lemo 写三种候选，主题不能往样片的故事上靠）。百分比按全片时长算。

### 模板 A：同一构图重画（首尾同框，环境变了）

适合：告别、时间流逝、一件事的「最后一次」。代码最省：首尾共用一张主构图，只换色指定/物件状态。
出处：《最后一碗面》（本仓库）；《Father and Daughter》同一处堤岸反复回到，人从小女孩到老人。

| 段 | 占比 | 做什么 |
|---|---|---|
| 起 | 0–8% | 主构图 A。第 0 帧有主体，3 s 内一个动作 + 一个声音（门铃、拉灯） |
| 承 | 8–60% | 手、物件、工序。每镜一个动作，切在动作上；中间插 1 个远景喘气镜 |
| 转 | 60–73% | 一个不靠表情的转折：物件状态突变（碗空了）、光变、人不在了。前后一拍真静默 |
| 合 | 73–100% | 回到主构图 A'：同一构图，换一套颜色/物件状态；最后一个颜色或声音熄掉 |

短片档：「承」拆成 3–4 次回到同一地点（季节、年龄、天气各不同），每次 30–60 s，每次只改一样东西。

### 模板 B：一个人一条路（横移长卷 / 旅程）

适合：寻找、离家、成长、穿越。人物一直很小，跟着走就行，故事在路上的东西里。
出处：huashu `11-长卷穿越片.md`（地面线、相机只进不退）；《Wind》各段首尾相接、一段接一段。

| 段 | 占比 | 做什么 |
|---|---|---|
| 出发 | 0–10% | 交代人、方向、一个想要的东西（一盏远处的灯、一封信） |
| 站点 × 3–5 | 10–80% | 每站一个环境 + 一件小事（停下、互动、继续走）；每站比上一站多一点阻力 |
| 抵达/揭晓 | 80–92% | 想要的东西兑现或落空；镜头这时才第一次停下或拉远 |
| 余韵 | 92–100% | 拉远见全貌，或回望来路 |

微短片只留 2 站。规则：所有事件相对「互动开始」定时；相机位置单调，不倒带（huashu 07 第 38 条）。

### 模板 C：规则—重复—打破（三次法则）

适合：喜剧、寓言、讽刺、一个世界的设定。人物只做机械的循环动作，正好避开代码人物的短板。
出处：《Wind》居民在大风里各有一套适应的日常（酒保、一个人打乒乓）。

| 段 | 占比 | 做什么 |
|---|---|---|
| 建立规则 | 0–20% | 用一个最清楚的例子让观众看懂这个世界的规则 |
| 重复变奏 | 20–70% | 同一规则 2–3 个变体，每个比上一个更巧或更荒诞；每个变体给足看懂的时间（lemo §7：笑点要给够时间） |
| 打破 | 70–88% | 规则失效或被反过来用一次——这就是转折 |
| 余韵 | 88–100% | 打破后的新状态，回扣第一个例子 |

## 4. 视觉规范

**人物（硬约束）**
- 走 `角色精细度.md` 的三条路之一，写进设定卡：`帧库`（有生图能力或用户给图）/ `只出手和背影` / `无`（物做主角）。
- 代码画的人物：全身高度 ≤ 1/4 画高，或剪影/逆光/背影；不出正脸，不做表情特写，不对口型 [经验值，来自雨夜便利店复盘「人物一直是最低分项」]。
- 手可以拍近景，但要画到位（`角色精细度.md` 交付线第 3 条「手是手」；《最后一碗面》全片主角就是一双手）。
- 动作只做「预备—动作—收尾」清楚的大动作（拉、推、举、放、走），关键动作按 0.2 s 一格放大检查（lemo §9）。

**用什么讲故事（代替表演）**
| 手段 | 例子 |
|---|---|
| 光 | 灯拉亮/拉灭；窗光从暖到冷；一个人走后房间暗一档 |
| 物件状态 | 碗满 → 碗空 + 硬币；两只杯 → 一只；自行车还在/不在 |
| 环境/天气 | 树叶季节、积雪厚度、潮水；同一地点不同时刻 |
| 尺度 | 大远景里一个小人 → 小人占满一扇窗 |
| 剪辑省略 | 不拍离开的过程，只拍离开后的空位（小津） |
| 声音 | 画外的门铃、脚步、车声交代画外的人 |

**构图与镜头**
- 每镜一个视觉焦点（D3）；关键时刻主体（物、手、剪影、亮窗）≥ 1/3 画高（lemo §8）——主体不一定是人。
- 景别 ≥ 3 种（D6）；运镜 ≥ 4 种（lemo §8）；每镜写「为什么这样拍」（lemo §4）。
- 推镜按 `镜头语言.md`：不连着三镜往里推，推了要拉或横移回来。
- 一个招牌镜头 + 一个只有这种画风能做的 native move，放在情绪高点（lemo §3、§8）。
- 构图层次：前景/中景/远景至少两层，大远景留白给环境（参考《Father and Daughter》《鹅鹅鹅》的大面积留白里的小人）。

**连贯性（第一版最容易丢）**
开画前写一张连贯性表（参照 `films/last-bowl/CONTINUITY.md`）：地理（谁在左谁在右、手从哪进）、光源方向、每件道具的颜色与画法、每一刀的出点和入点。切在动作上：上一镜最后一个动作在下一镜头几帧做完，方向和速度一致。

**转场**
默认硬切 + 切在动作上；匹配剪辑（杯口 → 月亮）；画风自己的转场（热气白闪、墨晕开）。不用默认叠化（《AI 到底该怎么用》评委判过叠化双影），不用转场留空白帧（lemo §10）。

**颜色**
一条和情绪曲线绑定的色指定变化（暖 → 冷、满彩 → 褪色），在风格卡里写成两三套色值，不在整张画上盖滤镜。

## 5. 声音规范

| 项 | 规范 |
|---|---|
| 台词 | 默认**无对白**（代码人物对不上口型，D7 很难过）。要旁白就做「字幕即旁白」或画外音，人不张嘴 |
| 旁白写法 | 说物件、说动作，不说破结局、不说情绪词（《最后一碗面》把「三十二年，就到今晚」改成「案板，三十二年没空过。」） |
| 三层 | 环境底（风、雨、街）+ 动作音效（每个看得见的动作都有声，材质对得上）+ 配乐（lemo §6） |
| 配乐 | 先定 BPM 和小节网格，剪切落在小节线（`check_skeleton.py` 的 `cutsOnBars`）；用画风声音调色板里的乐器，避开万能「钢琴 + 弦乐」（lemo §6）。《Wind》全片不用音乐，只有风声底 + 精选音效——喜剧/寓言类可以考虑 |
| 何时静音 | 转折前后、情绪高点前；静默后第一声要是全片最重要的声音之一（lemo §6）。静默 = 配乐停，环境底可以压到很低 |
| 声音做转场 | 短片档至少 2 次 J-cut / L-cut（下一场的声音先进，或上一场的声音拖过剪切）（lemo §6） |
| 响度 | 积分 -14 到 -16 LUFS，真峰值 ≤ -1 dBTP；有旁白时配乐低于人声 ≥ 10 dB（G4；lemo 母带 -14 LUFS） |
| 评委边界 | 评委只测量（响度、静默段位置、音画对位），好不好听由用户判（`review.md`） |

## 6. 校验逻辑

默认带上 G1–G7、D1–D7（D7 只在有口型/拟音对位时启用）。下面是本卡新增的 D10–D20。「必须/加分」是建议默认值，最终以用户确认的评审标准卡为准。

| 编号 | 检查项 | 必须/加分 | 阈值或判据 | 怎么测 |
|---|---|---|---|---|
| D1 | 静音看画面能说出谁、想要什么、阻碍、结果 | 必须 | 评委静音看全片后写出这四项，和 Treatment 的 logline 对得上 | 人判（静音看片） |
| D3 | 每镜一个视觉焦点 | 必须 | 每镜抽 1 帧标出焦点 | 抽帧 |
| D10 | 【量】时长在档内 | 必须 | 微短片 30–60 s；短片 120–300 s；或用户定的秒数 ±1 s | `ffprobe -show_entries format=duration` |
| D11 | 【量】镜头数与镜头时长 | 加分 | 微短片 8–16 镜、ASL 2.5–5 s；短片 ASL 3–7 s；单镜 ≤ 10 s（微）/ ≤ 15 s（短），标了「有意长镜」的除外 | `ffmpeg -vf "select='gt(scene,0.3)',showinfo"` 数切点，和 `skeleton.json` 对照（阈值 0.3 为经验值，画内换色指定会被误判成切点，人工复核） |
| D12 | 【美】开头 3 秒有钩子 | 必须 | 第 0 帧有主体（不是黑屏/片名）；3.0 s 内出现一个动作事件 + 一个声音事件（lemo §3） | 抽 0 s、1 s、3 s 三帧 + 查音效表 |
| D13 | 【美】人物不演戏 | 必须 | 代码画的人物：无正脸特写、无口型、全身 ≤ 1/4 画高或为剪影/背影/手；帧库人物过 `角色精细度.md` 交付线八条 | 每 2 s 抽 1 帧，挑出所有有人的帧并排看 |
| D14 | 【美】转折不靠表演讲 | 必须 | 写出转折所在镜头和所用手段（光/物件状态/环境/剪辑省略/声音），静音看能看懂 | 人判，对照 Treatment「转」一行 |
| D15 | 【美】全片连贯 | 必须 | 地理（左右、出入画方向）、光源方向、道具颜色画法全片一致；每一刀出点/入点按连贯性表 | 每个切点前后各抽 1 帧拼对照表 |
| D16 | 【量】静默落在转折前后 | 加分 | 微短片 ≥ 1 段、短片 ≥ 2 段静默（配乐停，整体电平 < -45 dBFS [经验值]，≥ 0.5 s），位置在转折/高点前后 5 s 内 | `ffmpeg -af silencedetect=n=-45dB:d=0.5`，对照 `skeleton.json` 的 `silences` |
| D17 | 【美】结尾回扣开头 | 加分 | 结尾和开头共用一个构图/物件/声音，且状态不同（lemo §3「一个转折」） | 首尾各抽 1 帧并排 |
| D18 | 【工】【量】剪切在网格上 | 加分 | 每个剪切落在小节线 ±1 帧，或标了 `offBarOk` | `python3 ~/.claude/skills/video-forge/scripts/check_skeleton.py skeleton.json` + 实测切点对照 |
| D19 | 【工】【量】字幕读得完 | 必须（有字幕时） | 停留 ≥ max(1.8 s, 字数 ÷ 4.5 + 1.5 s)；不压主体、不压 `noText` 镜头（lemo §7） | `check_skeleton.py`；lemo `core/render/readcheck.mjs` |
| D20 | 【美】短片档节奏不塌 | 加分（短片档） | 每 45–75 s 一次局势变化或新信息，列出每个点的秒数；没有连续 90 s 无变化的段落 | 人判，对照 beat sheet |
| D21 | 【工】【量】没有空画面、没有满屏蓝紫 | 必须 | film_gate 的「中段空画面」与「蓝紫底占比」不出红灯（题材要夜蓝时用 `--allow-blue-purple "理由"`）；「快速运动帧占比」只报告不拦——它是在解说片上标定的，慢节奏叙事片可能偏低 | `uv run ~/video-forge/vendor/huashu-art-motion/scripts/film_gate.py 成片.mp4` |

与 G7 的关系：静帧也可以是戏（《最后一碗面》S10 两手停在碗上 3 s），但画里要留一个循环（热气、灯摆、雪），所以 G7 照常适用。

## 7. 提示词模板

### 7.1 剧本 / Treatment（编剧 agent，3 个并行各攻一种结构）

```
你是动画短片编剧。为下面这支片写一份结构稿，只写结构 {A 同一构图重画 / B 一个人一条路 / C 规则—重复—打破} 这一种。
需求卡：{需求卡路径}   风格卡：{风格卡路径}   画风规则：{STYLE.md 路径}
硬限制：画面全部代码绘制，人物不演戏——不写表情、不写台词对白、不写口型；人物只能是 {剪影 / 背影 / 只出手 / 远景小人 / 帧库角色}。
故事必须靠光、物件状态、环境、尺度、剪辑省略和声音讲出来。
时长 {秒数} s，{横/竖} 屏，{BPM} BPM。
输出（≤ 1 页）：
1. Logline 一句话：谁、想要什么、什么变了、结局与开头有什么不同
2. 起承转合表：每段的秒数区间和画面（转折落在全片 55–73% 处）
3. 转折用的非表演手段（明确写是哪一种）
4. 开头第 0 帧画面 + 3 秒内的动作和声音
5. 结尾怎样回扣开头
6. 招牌镜头和 native move 各一个，放在哪一秒
7. 旁白/字幕（如有）：≤ {N} 句，只说物件和动作，不说破结局、不用情绪词
8. 这一稿最难用代码画的 2 处，以及绕开办法
不要往样片 {样片名} 的故事上靠。
```

### 7.2 分镜（摄影 agent）

```
按 skeleton.json 的镜头编号写 shots.md，不改任何时间。
每镜一行：| 编号 | 小节区间 | 景别·角度 | 运镜（固定/缓推/拉/横移/跟摇/焦点转移…，写幅度和缓动） | 画面里的焦点（一个） | 人物出现方式（剪影/背影/手/远景 ≤1/4 画高/无） | 讲故事的手段（光/物件/环境/声音） | 出点动作 → 下一镜入点动作 | 为什么这样拍 |
约束：景别 ≥ 3 种，运镜 ≥ 4 种；不连着三镜往里推；每个剪切切在动作上；
一个招牌镜头 {S?}；全片地理、光源方向、出入画方向按连贯性表 {CONTINUITY.md}。
最后附 6–9 格联系表的格子清单（格号、时间、画面一句话、镜头、声音、情绪）。
```

### 7.3 构建 agent 要点（写进每个镜头 agent 的提示词）

- 只读：`skeleton.json`、`shots.md`、`CONTINUITY.md`、风格卡、设定卡、样板镜头源码；时间只引用编号，不手写秒数。
- 人物：按设定卡的路线画；代码人物不画五官细节；手要「握住」物件（物在两掌之间）。
- 每镜一个主动作 + 1–2 个环境循环（雪、热气、灯摆），保证画是活的。
- 同一个 world → screen 函数算所有物件位置，镜头动时跟随效果不脱位（lemo §10）。
- 先粗剪级（构图、主体、关键动作对），整片能播再精修（`pipeline-style-film.md`「先出片」）。
- 交付前自查：静音看一遍本镜，能不能看懂这一镜在故事里的作用。

### 7.4 评委关注点（附在 `review.md` 的评委骨架之后）

```
本片类型：叙事动画短片（{微短片/短片}档）。额外要求：
- 先关掉声音完整看一遍，写出「谁 / 想要什么 / 阻碍 / 结果」，再开声音看第二遍。写不出来就是 D1 不通过。
- 找出转折所在的镜头，写出它靠什么讲（D14）；如果靠字幕或旁白说出来，判「部分」。
- 每个切点前后各抽 1 帧，查连贯性（D15）：左右、光向、道具、出入画方向。
- 所有有人物的帧并排看（D13）：有没有僵脸、穿模、像 AI 默认小人。
- 静默段用 silencedetect 量，列出秒数，对照转折位置（D16）。
```

## 9. 常见坑

1. **两小时写 Treatment、四小时磨三张静帧，一秒视频没出**（《最后一碗面》）。→ 风格帧 1–2 张定调即可，开工 1–2 小时内出整片粗剪（`pipeline-style-film.md`）。
2. **镜头各画各的，切过去像换了部片**（《最后一碗面》第一版，用户原话「没有连贯性，镜头不入」）。→ 开画前写连贯性表，每一刀写出点和入点。
3. **让代码人物当主角演戏**（雨夜便利店人物最低分；huashu：代码画的 Q 版「烂爆了」）。→ 人物小、远、剪影、只出手；或把主角换成物件。
4. **逐句/逐段配图，没有故事线**（《违背的青春》）。→ 先写 logline 和起承转合，镜头为故事服务。
5. **旁白说破结局或说情绪**。→ 说物件、说动作，留给画面。
6. **默认叠化转场**，出双影（《AI 到底该怎么用》）。→ 硬切 + 切在动作上，或画风自己的转场。
7. **每镜都慢推几个百分点** = PPT 感（`镜头语言.md` 第三节）。→ 推了要拉或横移回来；该停就停。
8. **跟拍长卷时镜头「倒带」**（huashu 07 第 38 条，17/24 段出现回退）。→ 相机位置取历史最大值再平滑。
9. **笑点/转折太快看不懂**（lemo §10）。→ 转折前后给足一拍，静默帮它落地。
10. **照着样片 demo 拍了一遍**。→ 交付前对照 `DEMO.md`：结构、开场、招牌镜头、运镜路径、配乐形状、结尾，至少 4 项不同（lemo §11）。
11. **为了过脚本加效果**（《违背的青春》为过卡点加脉冲闪动）。→ 指标服务于故事，D1 不过时任何数字都不算数。
12. **手拿东西还用平面拼**（《最后一碗面》第 1–3 版：手像机器结构，擀面杖擀到桌上，用户问「是不是画风不行」）。→ 分镜里有手碰物件就开工用三渲二（`pipeline-style-film.md`「做法先于画风」）。
13. **穿模只看截图**（《最后一碗面》第 5 版：自检说只剩三个小毛病，36 张画拇指全插在擀面杖里）。→ 接触逐张量顶点到表面的距离，改前改后用同一张画对比（`review.md`「自检怎么复核」）。
14. **配乐用 AI 生成**（《最后一碗面》：原配乐「诡异」，代码重写两版仍不过）。→ 从免费曲库挑 2–3 首给用户听（`music.md`）。
