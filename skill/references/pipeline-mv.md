# 产线：音乐 MV（mv-director）

生产交给 `~/.claude/skills/mv-director`（canvas 逐帧渲染，1080p60，听歌、对齐、卡点、审片脚本都在那里）。本文件只加它缺的关卡。第二阶段会再细化。

## 要用户提供的文件

| 文件 | 必需 | 说明 |
|---|---|---|
| 歌曲音频 `mp3` / `wav` | 必需 | 完整歌曲，越干净越好 |
| 歌词 `LRC` | 推荐 | 带时间戳更好；只有纯文本歌词也可以，脚本会强制对齐 |
| 片段起止 | 可选 | 只做副歌就给起止秒数（`--start` / `--end`） |
| 语言 | 必需 | 中文 / 日文 / 英文…… |
| 分轨（人声、伴奏） | 可选 | 没有就用 demucs 自动分 |
| 参考图、喜欢的 MV | 可选 | 只借感觉，不搬画面 |

旧素材：《违背的青春》在 `~/mv-xue/lyrics_fixed.lrc`、`~/mv-xue/song.json`。

## 加在 mv-director 前面的关卡

1. **需求卡**（追问清单）。
2. **解读卡**：这首歌讲什么，给 2–3 种解读（谁在说、对谁说、发生了什么、情绪怎么走），用户选一种。
3. **角色卡 + 场景卡**：一个贯穿全片的人物（或物件）和 1–3 个场景，出设定图确认。人物动作只用简单循环和姿态。
4. **分镜联系表**：按段落（主歌、副歌、桥段）6–9 格，用户确认。不许逐句抓关键词配图，画面要沿着一条故事线走。
5. 然后按 mv-director 的步骤生产（它的铁规矩全部保留）。
6. **盲审**：评委看遮住字幕的版本，判断画面本身是否讲清了故事；再看带字幕版查卡点。
