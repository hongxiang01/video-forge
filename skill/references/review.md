# 评审

## 原则（2026-11-05 改版）

旧做法的问题（用户原话"有点太敷衍了"）：评委只看联系表和零散抽帧，按"国际大奖"标准随手打分，分数没有依据，和作品要去的平台也对不上。改版后：

1. **标准由用户定，不由评委定。** 开工追问时，请用户选出视频类型，从该类型的默认检查项里勾选、删改或自己补充，再定好一票否决项，写成「评审标准卡」并请用户确认（`card-templates.md`）。评委只按这张卡判，不自己加标准。
2. **不用参考作品当锚点。** 样片好不好本身就说不清。每条标准都写成**能在画面里找到证据的检查项**：写"第 0 帧画面上有主体"，不写"开头有吸引力"。判定只有三档：通过 / 部分 / 不通过，每条都要附证据（帧号、秒数或测量值）。
3. **不同类型用不同标准。** 默认检查项按类型分开，见 `review-standards.md`。用户可以混用多个类型，比如"科普 + 特效"。
4. **评委必须看全片。** 每 2 秒抽 1 帧覆盖整片，镜头切换处连抽 3 帧（间隔 1/30 秒），再看完整的联系表。只抽几十帧不算看完。
5. **声音照实说明。** 评委 agent 只能测量声音（响度、峰值、静音段、音画对位），不能"听"。音色、配乐好不好听，由用户判断，评委不打这一项的分。
6. 只给评委：作品 + 评审标准卡 + 需求卡 + 风格卡。**不给我的自评和修改理由。**
7. 用户的话优先于评委。用户说"可以了"就停。

## 评委

| 评委 | 负责的检查项 |
|---|---|
| 美术评委 | 标准卡里归为"画面 / 叙事 / 风格"的项 |
| 工艺评委 | 标准卡里归为"动作 / 卡点 / 穿帮 / 技术 / 声音测量"的项，能用脚本量的必须用脚本量 |

同一位评委在后续轮次用 `SendMessage` 继续，保持口径一致。

## 评委提示词骨架

```
你是<美术/工艺>评委。只按下面这张「评审标准卡」逐条判定，不要自己加标准，也不要按"大奖"标准打分。
作品：<成片路径>；联系表：<路径>
评审标准卡：<路径>   需求卡：<路径>   风格卡：<路径>
看片要求：每 2 秒抽 1 帧覆盖全片（ffmpeg -vf fps=0.5），镜头切换处连抽 3 帧；先看完再判。
声音：只能测量（ebur128 / silencedetect / 对照时间轴查对位），不评价好不好听。
输出（写入 <评审文件路径>）：
1. 逐条判定表：| 编号 | 检查项 | 必须/加分 | 通过/部分/不通过 | 证据（帧号/秒数/测量值） | 不通过时怎么改 |
2. 一票否决项：有没有触犯，证据是什么
3. 结论：必须项通过 x/y，加分项通过 x/y；是否可以发布（必须项全部通过 + 无一票否决 = 可以发布）
4. 下一轮最值得改的 3 条（只能从"不通过/部分"里挑），每条写清在哪一帧、改成什么样
5. 你没看到或判断不了的地方（例如声音好不好听），照实列出
```

## 计分

- **能不能发布**：必须项全部通过，且没有触犯一票否决项。
- **质量分** = 加分项的通过比例（"部分"按 0.5 算），这是给用户看进步用的，不和别的作品比。
- 不出"获奖可能"这类没有依据的分数。

## 循环与停止

- 每轮：评委逐条判定 → 我只改"不通过 / 部分"的项 → 重新出片 → 同一位评委复判。复判时要逐条核对上一轮的问题是否解决。
- 每轮结束都把成片和判定表给用户看。
- 停止条件（满足任一）：
  - 必须项全部通过，且用户满意
  - 已经 3 轮
  - 用户喊停
- 每轮的结果记进 `~/video-forge/works/<slug>/scores.md`：必须项通过数、加分项通过数、这一轮改了什么。
