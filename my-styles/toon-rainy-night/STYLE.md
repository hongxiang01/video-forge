# 三渲二雨夜微缩 — 画风卡

> 一块放在木底座上的日本街角模型，雨夜，霓虹。三渲二描边、干净的色块明暗、湿地面上的倒影；暗处是夜，亮处是店。像日本动画里某个深夜社区的一角，被做成了可以拿在手里转的收藏品。
> 参考（只借语法）：日本动画背景美术的雨夜街景（冷暗环境 + 暖色光源 + 湿地反光）、模型玩具的展示底座、三渲二动画的描边与色阶。不借任何具体作品的构图、角色、店名或标志。

来源作品：`works/rainy-corner-diorama/index.html`（v9）。

## 1. 本质与禁区

- **模型感**：整个世界放在一块正方形木底座上，四边露出切面；底座外是桌面和接触阴影，不再有世界。
- **三渲二**：硬分界的三阶明暗 + 深蓝紫描边；不要写实材质、不要 PBR 金属感。
- **夜是暗的**：环境压在低亮度，只让光源周围亮起来。用户原话：「灯光拍扁还是过于亮」——整体亮会把体积拍扁，这是第一禁区。
- **光有来处**：每一片亮都要有灯（店内、路灯、招牌、贩卖机、灯笼），亮区形成光池，光池之间是暗。
- **湿**：路面有积水倒影、雨丝、溅点、涟漪；倒影只出现在水洼里，不是全地面镜子。

不是：写实渲染、赛博朋克（不要满屏霓虹和紫粉泛滥）、Q 版玩具（比例按真实街道，不卡通化）、扁平插画（有真实体积和投影）。

## 2. 材质与渲染（数值来自 v9）

| 项 | 值 |
|---|---|
| 材质 | `MeshToonMaterial` + RGB 三阶 ramp：`(28,26,46)` / `(128,124,158)` / `(255,248,240)`（暗阶偏紫，亮阶偏暖） |
| 描边 | `OutlineEffect` 粗细 0.0034，颜色 `[0.05, 0.04, 0.12]`；雨、光晕、贴花、细线不描边 |
| 深度 | `logarithmicDepthBuffer: true`，近裁剪 0.5（否则描边外壳和地面打架出条纹） |
| 管线 | HDR 半浮点渲染目标 → Bloom(强度 0.5，半径 0.4，阈值 1.0) → 调色 pass |
| 调色 | 高光肩部：0.75 以上压缩；暗部轻微提亮防死黑；冷暗暖亮分离色调；暗部降饱和、中亮部饱和 1.1；暗角 0.35；抖动去色带 |
| 阴影 | 月光主光投影 2048，PCFSoft，场景静止只烘焙一次 |
| 倒影 | 平面镜反射（斜裁剪面），0.45 倍分辨率，水洼着色器：菲涅尔、去饱和 50%、噪声条纹、边缘噪声淡出 |
| 圆角 | 大件用圆角盒（r ≥ 0.18），小件直角；r128 的圆角盒要重写 UV |

## 3. 色彩

- 环境：雾色 `#15173a`，半球光 天 `#34416c` / 地 `#2a2230`，强度 0.32。
- 主光（月光）`#a3abd0`，0.72，从左后上方来，给体积；轮廓光 `#6f5cff` 0.28。
- 暖光源：路灯 `#ffa050`（聚光，形成光池）、店内 `#c6f5e8` 冷白、灯笼与小巷暖橙。
- 霓虹只做点缀：招牌、贩卖机（红 = 热饮、蓝 = 冷饮）、小吃店霓虹各一处，不要连片。
- 文字只用真实可读的日文（止まれ、空車、あったか〜い），绝不出现镜像字。

## 4. 动态

- 雨丝随地面高度落到正确的面上（屋顶、雨棚、人行道、路面各自高度）。
- 溅点、涟漪随机相位；路灯偶尔闪一下（概率很低）。
- 默认缓慢自转（0.25），用户拖动后停 8 秒再恢复。
- 人物静止或极小动作；不演戏（代码做的表情和手部动作必僵）。

## 5. 镜头

- 默认机位：方位 22°，仰角 17°，视角 32°，按画幅自动算距离，让底座刚好装满。
- 低机位才看得到湿地面倒影，所以默认压低。
- 交互：拖拽旋转、滚轮缩放、限制不能钻到底座下面。

## 6. 声音（做成视频时）

雨声底 + 远处车过积水 + 便利店自动门开合提示音 + 冷柜嗡鸣；配乐只用 lo-fi 钢琴或电钢，音量压低。

## 7. 评委遗留意见（下一版要补）

- 人物和车辆建模太简单，离「获奖」最远的一项。
- 墙面细节密度不够（海报、污渍、管线、招牌层次）。
- 技术：对数深度 + 三遍渲染 + 9 盏灯，性能偏重；路缘没有落差。
