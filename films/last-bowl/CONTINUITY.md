# 连贯性表（粗剪第 2 轮起，所有镜头都按这里做）

用户看完第一版的意见：「没有连贯性，镜头不入」。原因：10 个镜头各画各的，桌子、窗、光、师傅站哪边、手从哪进都不一样，切过去像换了一部片。下面是全片共用的约定和每一刀的交接。

## 一、全片共用

| 项 | 约定 |
|---|---|
| 地理 | 师傅站在案板**近侧**。正俯和主构图（A / A'、S2、S4、S12）里他的手和袖子**一律从画面下沿（或下角）进**；窗在远侧（画面上方）。灶台在案板左边（S7）。递碗的柜台（S9–S11）：师傅在**左**，老主顾在**右** |
| 案板 | 同一块案板：暖灯下木色、木纹、木节画法和 plates.js 的暖灯台面一致（光圈内 `#A86E3C`，光圈外 `#7A4A2A`）；正俯镜头里木板横向铺 |
| 光 | 屋里只有一盏吊灯，在**左上**；灯下一圈琥珀光池，光池外压暗。窗外冷光从远侧来。S1 拉亮后到 S12 结束一直是暖灯色指定 |
| 窗 | 只要拍到窗，就是 A 里那扇：三格、两道窗棂、玻璃上褪色白漆的**反写「手擀面」**、窗顶卷着的卷帘门箱、右格里路灯的金光。从屋里看字是反的，S8 从街上看是正的 |
| 手 | 掌宽按 TREATMENT §4.2 的镜头表。袖子永远是同一件：旧白厨师服、发黄的袖口 `#C8B07A`；前臂一直延伸到画框外，不在画面中间断掉。皮肤只用 `C('skin', light)`，不拿乘法整体压色。老主顾（只在 S10 / S11）：藏青棉袄袖、指节冻红 |
| 道具 | 红沿碗处处是同一只（白瓷、红沿 `#C8323A`，props.bowl 的画法）；擀面杖就是 A 里那根（木色、直径 4.5 cm、两头圆）；面团和面片用 §4.4 的面团色，从 S2 到 S6 一个颜色；切面刀是**长方形薄刃切面刀**，木柄在刀背后端，不是砍刀 |
| 面粉 | `#F4EBD8`，影 `#9C83AB`，平涂硬边，散开的粉有碎边和小粒，不画成一整块纸片 |
| 转场 | 只用硬切；S7→S8 白闪（已有）。**切在动作上**：上一个镜头最后一个动作，下一个镜头头几帧接着做完，方向和速度一致 |

## 二、每一刀怎么接

| 剪切 | 出点（上一个镜头最后 0.5 s） | 入点（下一个镜头头 0.5 s） |
|---|---|---|
| S1→S2 3.0 | 暖灯刚亮，灯还在摆，光圈在台面上来回扫 | 正俯同一块案板的灯圈里，光池还带着同一个摆的余晃；面粉开始落下，节奏和 S1 窗外的雪一样慢 |
| S2→S3 6.0 | 手指刚从面窝里抬起 | 面已经和成团（时间跳）；6.00 第一推落在拍上。面团色和 S2 的面一致 |
| S3→S4 9.0 | 第四推把面团转过来 | 正俯：面团已被压扁，双手**手掌平按**在杖上，9.00 第一下推杖 |
| S4→S5 12.0 | 杖停在面片近边，双手搭在杖上 | 12.00 手腕先沉（预备），把搭着面片的同一根杖举向吊灯 |
| S5→S6 15.0 | 面片透光举在灯前 | 叠好的面片在案板上，15.00 第一刀落在拍上 |
| S6→S7 18.0 | 双手抓起两把面抖开 | 正俯锅口：一把面从**画面下沿**（师傅那侧）落进滚水 |
| S7→S8 21.0 | 热气扑镜头，白闪 | 从白里亮回雪夜天空，开始降镜 |
| S8→S9 24.0 | 落在面馆暖光的窗上 | 柜台上的红沿碗，焦点从热气拉到碗上 |
| S9→S10 27.0 | 葱花落定，一道高光沿碗沿滑过 | 同一只碗（面条、葱花的摆法一样）被师傅从**左边**推过柜台 |
| S10→S11 30.0 | 静帧，热气在动 | 同一构图，碗空了（筷子横搁、三枚硬币），真静默 |
| S11→S12 33.0 | 师傅的手从左边把空碗端走 | 正俯：碗刚离开的案板（留一圈淡淡的碗底水印），师傅的手从**下沿**拿湿布进来擦 |
| S12→S13 36.0 | 擦出一道弧，手抬起出画（往下沿） | 主构图 A' 暖灯版：台面擦净，弧痕在 A' 里同一个位置（屏幕约 (435, 922) → (1294, 746)） |
